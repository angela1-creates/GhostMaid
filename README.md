# Ghost Maid

Ghost Maid is a playful cleaning game where players switch between a trash bag, blow dryer, scrubber, and magnifying glass to clean rooms and interact with mischievous ghosts.

- **Original physical-board version:** [View the design case study and gameplay recording](https://angela1-creates.github.io/projects/ghost-maid/). The original game was designed for Carnegie Mellon University Entertainment Technology Center’s (CMU ETC) physical board interface.
- **Playable web adaptation:** [Launch Ghost Maid](https://angela1-creates.github.io/GhostMaid/) in a desktop browser. This Unity WebGL build uses a mouse and keyboard.
